# Sharpe Ratio and Risk-Adjusted Return

## The idea
Two investments with the same return aren't equally good if one took far more risk to earn it.
**Risk-adjusted return** measures how much return you got per unit of risk.

## The Sharpe ratio
Sharpe ratio = (portfolio return − risk-free rate) ÷ standard deviation of the portfolio's returns.

- The **risk-free rate** is usually the yield on short-term U.S. Treasury bills.
- Example: an 8% annual return, a 3% risk-free rate, and 10% volatility give a Sharpe ratio of
  (8% − 3%) ÷ 10% = **0.5**.

Higher is better: more excess return for each unit of volatility.

## How to use it
- Compare investments or portfolios **over the same time period**.
- Rough rules of thumb treat values above 1 as strong, but levels depend heavily on the period and
  market conditions.

## Limitations
- It uses standard deviation, which treats upside and downside swings the same.
- It is backward-looking; a high past Sharpe ratio doesn't guarantee future results.
- Short periods produce unreliable estimates.
